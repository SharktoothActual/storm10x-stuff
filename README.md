# storm10x-stuff

This repo contains a variety of useful Linux-related things for the X-Plus Storm10x Mini Laptop, specifically the version with the Intel i5-1235U.

This repo is for Linux only, there will likely not be anything for Windows or BSD here.
That being said, some of the information may transfer over. I make no guarantees.

### **Most of my stuff should work with whatever distro you want to use.**

Quick set of recommendations for this laptop:
* Beginners: Fedora
* Journeymen: Arch
* My choice: Gentoo

### Contents
| Directory | Contents |
| --- | --- |
| `accelerometer` | Getting tablet mode working in KDE (good) and GNOME (hacky) |
| `bios` | A copy of the BIOS that isn't some random post on a forum hosted behind MEGA's crappy service. |
| `bios-splash` | This  has copies of the BIOS's custom splash screen, extracted from the BIOS itself. More info in there. |
| `plymouth-theme` | A reworked version of `plymouth-modern-bgrt` by @glics. Repo is [here](https://github.com/glics/plymouth-modern-bgrt). |
